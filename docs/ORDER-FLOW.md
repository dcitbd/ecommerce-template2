# Order Flow & Calculation Policy

### Weight-Based Delivery Calculation:
- **Collect from Office**: 0 Tk (Free Pickup in Cumilla Office)
- **Inside Dhaka**: 90 Tk for up to 1.0 kg; +20 Tk for each additional kg or fraction thereof (1.1kg = 110 Tk, 2.0kg = 110 Tk, 2.1kg = 130 Tk).
- **Outside Dhaka**: 130 Tk for up to 1.0 kg; +20 Tk for each additional kg or fraction thereof (1.1kg = 150 Tk, 2.0kg = 150 Tk, 2.1kg = 170 Tk).

### Order Status Lifecycle:
`Pending` → `Accepted` → `Confirmed` → `Sent` → `IN-Courier` → `Delivered` / `Cancelled` / `Returned`.
