# Authentication & Role Protection

- **Customer Auth**: Registration with phone verification, math captcha, profile picture, full delivery address.
- **Guest Auto-Account**: When placing an order without an account, a customer account is automatically provisioned and login credentials are dispatched via SMS & Email.
- **Password Reset**: Phone-based 4-digit OTP verification.
- **Admin Access**: Role-based access control (Super Admin, Admin, Manager, Worker).
