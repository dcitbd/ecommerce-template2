# API Endpoints & Connectors

### Courier APIs
- **Steadfast Courier API**: Automated parcel booking and real-time tracking webhook.
- **Pathao Courier API**: Bulk consignment upload and status synchronization.
- **RedX Courier API**: Automated parcel delivery dispatch.

### Payment Gateways
- **bKash**: Merchant checkout & instant callback.
- **Nagad**: Digital payment gateway integration.
- **Rocket**: Dutch-Bangla mobile banking.
- **SSLCommerz**: Multi-card & Internet banking gateway.
