# Techno World BD - Platform Documentation

Welcome to the comprehensive technical documentation for **Techno World BD**, an enterprise-grade e-commerce application designed for wholesale, pre-order, and retail camera and optics businesses in Bangladesh.

## Core Highlights
- **Direct Sourcing Channels**: Dubai, Hong Kong, Russia.
- **Fast Turnaround**: 10-15 days pre-order fulfillment.
- **Dual Architecture**: Runs as a lightweight static SPA for **GitHub Pages** / cPanel and bridges with **Supabase** for database, edge functions, and storage.
